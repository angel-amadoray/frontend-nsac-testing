# Future Improvements & Feature Proposals

This document outlines potential improvements and new functionalities proposed for the Space Exploration Platform. These enhancements aim to improve user engagement, accessibility, educational value, and overall usability.

## 1. Citizen Science Participation – Discovery Registration

**Proposed Feature:** `[ REGISTER A DISCOVERY ]`

Introduce a citizen participation feature that allows users to contribute to astronomical observation and discovery.

A dedicated **[ REGISTER A DISCOVERY ]** button would allow citizens to report newly identified celestial objects, unusual astronomical events, or interesting movements observed in the platform's astronomical images.

### Proposed Functionality
- Allow users to submit potential astronomical discoveries directly through the platform.
- Provide a registration form to describe the observed object or movement.
- Allow users to identify the specific image, astronomical region, or sector where the observation was made.
- Include optional image references and additional observations as supporting evidence.
- Implement a review and validation process to allow qualified researchers or administrators to evaluate submitted discoveries.

### Main Objective

Encourage citizen science by transforming users from passive observers into active participants in astronomical exploration.

This feature would create opportunities for public collaboration, scientific curiosity, and community involvement in space research.

## 2. Contextual Glossary – Interactive Learning Experience

**Proposed Feature:** Global Contextual Glossary Integration.

Improve the existing glossary functionality by making scientific definitions accessible throughout the entire platform, rather than limiting them to a dedicated glossary section.

The objective is to help users understand unfamiliar astronomical terminology and complex scientific concepts while navigating the website.

### Proposed Functionality
- Make important scientific terms accessible across all platform sections.
- Highlight technical or potentially unfamiliar terminology within descriptions, information panels, and astronomical visualizations.
- Allow users to interact with highlighted terms to display floating definition windows or contextual tooltips.
- Provide clear, concise, and accessible explanations for complex astronomical concepts.
- Include links to related terms when additional context is necessary.
- Maintain a centralized glossary database to ensure consistency across the platform.

### Main Objective

Create an educational browsing experience in which users can learn new scientific vocabulary naturally while exploring astronomical content.

Instead of interrupting navigation to search for definitions, users would be able to understand concepts directly within their original context.

## 3. Interactive Documentation – Guided Tutorial Mode

**Proposed Feature:** Interactive Onboarding and Tutorial System.

Introduce an automated tutorial system designed to guide users through the platform's interface and explain its available functionalities.

The experience would begin with a welcome message when users first access the platform, followed by a sequence of floating informational windows that guide them through the main sections and interactive tools.

### Proposed Functionality

**A. Welcome Introduction**
- Display a welcome window when users enter the platform for the first time.
- Provide a brief introduction to the platform's purpose and astronomical exploration capabilities.
- Offer the option to start the guided tutorial or explore independently.

**B. Interactive Guided Navigation**
- Display contextual floating windows that guide users through the interface.
- Highlight specific buttons, navigation elements, controls, and interactive components.
- Explain the purpose and functionality of each highlighted element.
- Provide navigation controls such as Next, Previous, Skip, and Exit Tutorial.
- Adapt tutorial instructions to the section currently being explored.

**C. Tutorial Access Through the Navigation Bar**

Add a permanent tutorial entry to the main navigation bar.

Suggested label:

`[ ENTER TUTORIAL MODE ]`

Alternative labels:
- `[ START GUIDED TOUR ]`
- `[ HOW TO USE THE PLATFORM ]`
- `[ EXPLORE THE TUTORIAL ]`

Users should be able to activate the tutorial at any time, even after dismissing the initial welcome message.

**D. User Experience Improvements**
- Allow users to restart the tutorial whenever necessary.
- Avoid displaying repetitive welcome messages to returning users.
- Provide short explanations instead of overwhelming users with extensive documentation.
- Ensure that tutorial windows do not obstruct essential interface elements or interfere with active visualizations.

### Main Objective

Make the platform accessible to both experienced astronomy enthusiasts and users with little or no technical knowledge.

The tutorial system should reduce the learning curve, encourage exploration, and ensure that users understand how to interact with the platform and take advantage of its available features.

---

## 4. Overall Vision

These proposed improvements share three fundamental objectives:

1. **Scientific Participation:** Encourage users to contribute observations and participate in citizen science.
2. **Educational Accessibility:** Make complex astronomical terminology and concepts understandable to a broader audience.
3. **Intuitive Navigation:** Provide guidance and documentation that allow users to explore the platform independently and confidently.

The long-term vision is to transform the platform into more than an astronomical visualization tool: an interactive educational environment where exploration, learning, and citizen participation work together.

**Status:** Proposed – Future Development.

These features are conceptual proposals and have not yet been scheduled or implemented.
